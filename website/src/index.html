LOCAL SETUP
View repository ↗
01

Clone the repository

git clone https://github.com/thulasisrinidhi2206-sn/Repolens.git
02

Install dependencies and build

cd Repolens && npm install && npm run build
03

Load the extension in Chrome

  1. Open chrome://extensions and switch on Developer mode.
  2. Select Load unpacked and choose the project’s extension/ folder (the folder containing manifest.json).
  3. Start the backend with npm run dev:backend for local analysis.
ⓘ

Repository analysis requires the backend and GitHub API access. Gemini review is optional; sandbox preview requires Docker running on the backend host.

Just here to preview the landing page? npm run dev:website Build static files with npm run build:website Deploy website/dist/ to a static host.
